Connexion admin

Les comptes joueurs se créent librement depuis la page d'accueil, mais le statut admin ne se donne pas tout seul : après avoir créé (ou choisi) un compte, le propriétaire du site l'élève une seule fois en admin directement dans Supabase Dashboard → SQL Editor avec : 

update public.profiles set is_admin = true
where id = (select id from auth.users where email = 'ton-email@exemple.com');

Connecte-toi ci-dessous avec ce compte pour approuver des niveaux et gérer les signalements.
